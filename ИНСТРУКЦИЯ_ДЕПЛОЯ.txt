ШАГ 1: ПОДКЛЮЧИТЕСЬ К СЕРВЕРУ
═══════════════════════════════════════════════════════════════

ssh root@lms.it-uae.com

или если у вас другой пользователь:

ssh your-user@lms.it-uae.com

Введите пароль когда потребуется.

═══════════════════════════════════════════════════════════════

ШАГ 2: ЗАПУСТИТЕ АВТОМАТИЧЕСКИЙ ДЕПЛОЙ
═══════════════════════════════════════════════════════════════

Скопируйте и выполните эту команду:

curl -sSL https://raw.githubusercontent.com/rakhatutebayev/snapcheck/main/install.sh | bash

ВНИМАНИЕ: Если скрипт попросит sudo пароль - введите его.

═══════════════════════════════════════════════════════════════

ЧТО ДЕЛАЕТ СКРИПТ (автоматически):
═══════════════════════════════════════════════════════════════

✅ Устанавливает Docker и Docker Compose
✅ Клонирует код из GitHub (последняя версия)
✅ Создаёт файл .env с безопасными ключами

═══════════════════════════════════════════════════════════════

После завершения скрипта проверьте:

1. Откройте в браузере: https://lms.it-uae.com
   (должна открыться страница входа)

2. Проверьте API: https://lms.it-uae.com/api/health

   Password: admin123

ПОЛЕЗНЫЕ КОМАНДЫ НА СЕРВЕРЕ
═══════════════════════════════════════════════════════════════

# Перейти в папку приложения
cd /opt/SnapCheck

# Посмотреть статус контейнеров
sudo docker-compose -f docker-compose-traefik.yml ps

# Посмотреть логи
sudo docker-compose -f docker-compose-traefik.yml logs -f

# Перезапустить сервисы
sudo docker-compose -f docker-compose-traefik.yml restart

# Остановить всё
sudo docker-compose -f docker-compose-traefik.yml down

# Обновить из GitHub
sudo git pull origin main
sudo docker-compose -f docker-compose-traefik.yml build
sudo docker-compose -f docker-compose-traefik.yml up -d

TROUBLESHOOTING (если что-то не работает)
═══════════════════════════════════════════════════════════════

ПРОБЛЕМА: SSL-сертификат не получается
РЕШЕНИЕ:
  - Проверьте DNS: dig lms.it-uae.com +short
  - Убедитесь что домен указывает на IP сервера
  - Проверьте порты: sudo netstat -tulpn | grep -E ':(80|443)'

ПРОБЛЕМА: Backend не запускается
РЕШЕНИЕ:
  - Смотрите логи: sudo docker-compose -f docker-compose-traefik.yml logs backend
  - Перезапустите: sudo docker-compose -f docker-compose-traefik.yml restart backend

ПРОБЛЕМА: База данных недоступна
РЕШЕНИЕ:
  - Проверьте: sudo docker-compose -f docker-compose-traefik.yml exec db pg_isready
  - Перезапустите: sudo docker-compose -f docker-compose-traefik.yml restart db
